# Volume 03 — Original Matter OM-101 ~ OM-130

> 두 번째 세대는 “더 강한 물질”보다 **용량·피로·카운터·부산물**을 가진 물질을 우선한다.

### OM-101 — Hysterene / 이력석

**도감** — 뜨거웠던 사실을 기억하는 돌. 같은 온도라도 과거에 따라 다른 상태를 고집한다.

- **Family:** 열·압력·피로
- **Movement:** `STATIC`
- **상태:** `CANDIDATE`
- **핵심 행동:** >140°C에서 HOT_PHASE, <90°C에서만 복귀. 중간에서는 이전 상태 유지
- **획득/생산 후보:** Phase-Wax 함침 세라믹 열사이클. U
- **카운터 / 실패:** 과열 시 두 상태 고착. **창작**

### OM-102 — Thermocline Ore / 열경사광

**도감** — 열 다이오드, 보일러 제어.

- **Family:** 열·압력·피로
- **Movement:** `STATIC`
- **상태:** `CANDIDATE`
- **핵심 행동:** 한 면→반대 면 k*=6, 역방향 k*=0.3
- **획득/생산 후보:** 방향성 소결. R
- **카운터 / 실패:** 뒤집어 설치하면 기능 반전. **창작**

### OM-103 — Thermospall / 열박리암

**도감** — 열채굴, 지각 붕괴 퍼즐.

- **Family:** 열·압력·피로
- **Movement:** `STATIC`
- **상태:** `CANDIDATE`
- **핵심 행동:** 이웃 간 ΔT>180°C이면 외곽 1셀씩 박리되어 분말화
- **획득/생산 후보:** 화산지대 자연 산출. C
- **카운터 / 실패:** 균일 가열에는 매우 강함. **창작**

### OM-104 — Cryo-Foam / 냉팽창포

**도감** — 냉동 부력, 임시 차폐벽.

- **Family:** 열·압력·피로

- **획득/생산 후보:** Gelid Silt+Anchor-Foam 공정. U
- **카운터 / 실패:** 따뜻한 방에서 붕괴. **창작**
