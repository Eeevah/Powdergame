# Volume 03D — VX 강화 파생형

강화형은 상위호환이 아니라 **새 작동 모드 + 새 실패 모드**를 가져야 한다.

### VX-001 — Pyrostor-X / 계단축열석

**도감** — 다단 열저장, 방향성 방출, 충전도 시각화, 열전출력.

- **상태:** `CANDIDATE_DERIVATIVE`
- **강화 행동:** 다단 열저장, 방향성 방출, 충전도 시각화, 열전출력
- **생산 후보:** Pyrostor+Phase-Wax 열사이클; R
- **카운터 / 피로:** 급랭, 과충전, Resonac 진동

### VX-002 — Baroclast Weave / 압직포석

**도감** — 감압 자가봉합, 충격 후 발포, 반복 회수.

- **상태:** `CANDIDATE_DERIVATIVE`
- **강화 행동:** 감압 자가봉합, 충격 후 발포, 반복 회수
- **생산 후보:** Baroclast+섬유 슬래그; U
- **카운터 / 피로:** 수분 오염, 반복 피로

### VX-003 — Tensor-Glass / 텐서유리
