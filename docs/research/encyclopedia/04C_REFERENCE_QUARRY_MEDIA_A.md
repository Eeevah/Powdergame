# Reference Quarry

> **출시 콘텐츠 목록이 아니다.** 익숙한 이름에서 행동 문법만 캐낸다. 유명 작품 고유명사는 `REFERENCE_ONLY`.

## 창작물에서 가져온 것

### Spice Melange

**도감/참고상** — 《듄》의 스파이스. 사막에서만 나오고, 물에 약하다.

- **상태:** `REFERENCE_ONLY`
- **Mechanic quarry:** POWDER. 《듄》의 스파이스. 사막에서만 나오고, 물에 약하다. 모이면 공기가 일렁이고, 태우면 이상한 주황 연기가 된다. 게임에서는 “귀하고 중독성 있는 가루”. 초능력은 넣지 않는다. 대신 주변 GAS가 조금 더 오래 산다.
- **처리 원칙:** 직접 채택 금지. 행동 family로 변환 후 독자 Matter 후보와 비교.
