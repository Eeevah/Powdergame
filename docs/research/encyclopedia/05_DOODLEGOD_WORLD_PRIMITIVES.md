# Volume 05 — Doodle-God World Primitives

> Matter만으로 세계를 만들 수는 없다. 어떤 것은 Field이고, 어떤 것은 Agent이며, 어떤 것은 Concept 또는 Meta Rule이어야 한다.

이 권은 장기적인 세계 창조 문법을 위한 후보이며 M0 구현 범위를 확장하지 않는다.

- **유형:** 물질+정보
- **상태:** `WORLD_PRIMITIVE_CANDIDATE / FUTURE`
- **핵심 행동:** 접촉한 신호 패턴을 저장

| 조합/조건 | 발견 |
|---|---|
| 물 + 열 | 증기 |
| 모래 + 고열 | 유리 |
| 씨앗 + 물 + 영양 | 식물 |
| 생명 + 늪 | 미생물 |
| 금속 + 전기 | 전도 회로 |
| 기억 젤 + 전기 | 기억 회로 |
| 기억 회로 + 신경 점액 | 원시 신경망 |
| 신경 점액 + 씨앗 | 사고하는 덩굴 |
| 사고하는 덩굴 + 언어 포자 | 이야기 숲 |
| 이야기 숲 + 불 | 신화 재 |
| 신화 재 + 물 | 신화 잉크 |
| 신화 잉크 + 금속 | 룬 |
| 룬 + 회로 + 마나 | 마법 회로 |
| 확률 결정 + 번개 | 확률장 |
| 확률장 + 생명 | 고변이 생태계 |
| 시간 먼지 + 얼음 | 정지된 순간 |
| 정지된 순간 + 열 | 시간 증기 |
| 빛 + 공허 거품 | 그림자 물질 |
| 거울물 + 인과 실 | 인과 고리 |
| 인간 + 언어 + 식량 잉여 | 정착지 |
| 정착지 + 네트워크 + 지식 | 문명 |
| 문명 + 기록 결정 | 역사 |
| 역사 + 신화 잉크 | 종교 |
| 종교 + 마나 | 신성장 |
| 신성장 + 생명 | 신화 생물 |
