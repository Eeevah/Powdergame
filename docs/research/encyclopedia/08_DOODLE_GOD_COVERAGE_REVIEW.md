# Volume 08 — Doodle God Coverage Review

## Status

- Type: `DERIVED / REFERENCE_REVIEW`
- Authority: non-authoritative research
- Purpose: review Doodle God-style elements broadly, not just physical materials, and decide what layer each idea belongs to in Powdergame.
- Important: Doodle God names/combinations are **reference mechanics**, not content to copy wholesale.

Different Doodle God editions contain different element sets and episode groupings. This review uses the classic multi-episode element guides and the Doodle God Blitz group/cheatsheet as broad coverage references rather than treating one edition as the only canon.

## 1. Core conclusion

Doodle God is useful to Powdergame because it treats **matter, organisms, manufactured objects, energy, society, magic and abstractions as one discovery graph**.

Powdergame should preserve that breadth in the encyclopedia, but not force everything into the Matter layer.

```text
Doodle-God-like element
→ ask what kind of thing it actually is
→ Matter / Phenomenon / Field / Agent / Structure / Concept / Meta
→ define a discoverable causal chain
```

This lets the encyclopedia be generous while the simulation core stays disciplined.

## 6. Manufactured materials and production chains

This is one of the strongest lessons to borrow.

Doodle God repeatedly turns natural resources into manufactured outputs:

```text
Clay → Ceramics / Bricks
Limestone + Clay-like chain → Cement
Cement + Water / aggregate logic → Concrete
Tree → Wood
Plant fiber → Paper / Fabric
Metal + Steam → Boiler-like device
Sand + Heat → Glass
```

Powdergame should emphasize **world fabrication rather than menu crafting**.

Recommended high-value chains:

- Clay → Wet Clay → Brick / Ceramic
- Sand + high Heat → Glass
- Limestone + process → Lime/Cement family
- Cement + Water + aggregate → Concrete
- Wood → Charcoal / Ash / Smoke depending thermal path
- Ore → Metal → Molten Metal → cast structure
- Resin → cured polymer / Amber-like solid
- Oil → Tar / Fuel families through simplified processing
- Saltpeter + sulfur + carbonaceous material → Gunpowder-like explosive family (exact recipe can be abstracted for game safety/simplicity)

## 10. Technology-age coverage

Doodle God Blitz/technology-era references include things such as Computer, Rocket, Internet, Satellite, Laser, TV, Cell Phone and Nuclear Bomb.

Powdergame should interpret these as proof that the discovery graph may eventually extend beyond materials.

Do not implement `Computer` as a cell.

Instead:

```text
conductive paths + switches + memory material
→ Logic Circuit

reliable circuit + memory + clock
→ Computer concept

propellant + chamber + nozzle + controlled combustion
→ Rocket concept
```

This is much closer to Powdergame's simulation identity than symbolic A+B recipes.

## 11. Doodle God combination philosophy worth keeping

The original game often uses memorable symbolic combinations rather than strict physical chemistry. Examples in classic guides include chains such as Water + Air → Steam, Fire + Sand → Glass, Clay + Fire → Bricks, and resource/tool combinations that produce higher-level concepts.

Powdergame should keep the **surprise and semantic leap**, but convert recipes to causal world conditions whenever possible.

```text
Doodle-style:
A + B = C

Powdergame-style:
A establishes condition X
B responds through its own rule
world reaches stable/observable phenomenon C
Dictionary recognizes discovery C
```

Example:

```text
Sand + Fire = Glass
```

becomes:

```text
Sand reaches sufficiently high Temperature
→ molten/sintered transition
→ cooling
→ Glass
```

The discovery is the same; the world is doing the explanation.

## 12. Coverage decision matrix

### Include aggressively in encyclopedia

- physical elements and common materials;
- biological species/archetypes;
- manufacturing products;
- energy/field concepts;
- tools/structures/technology;
- social concepts;
- magic/fantasy concepts;
- meta concepts if they inspire a reusable future system.

### Implement as Matter when

- it occupies space meaningfully;
- movement/temperature/pressure/reaction rules give it a distinct identity;
- local interactions are readable;
- it does not require pretending a concept is a substance.

### Implement as another primitive when

- it is fundamentally an event, field, agent, structure, semantic discovery or global rule.

### Reference-only / merge when

- it is a joke, one-off quest object, branded/copyrighted identity, palette swap or duplicate mechanic;
- its only difference is narrative flavor;
- it would require a bespoke subsystem for one gimmick.

## 14. Recommendation

Powdergame should be **more inclusive at the encyclopedia level than at the runtime level**.

The useful mental model is:

```text
Anything interesting may enter the encyclopedia.
Not everything becomes Matter.
Not everything is implemented now.
Nothing is discarded merely because it belongs to a later layer.
```

That captures the best part of Doodle God — the feeling that almost any idea can eventually belong to the world — while preserving Powdergame's much stronger causal simulation model.
